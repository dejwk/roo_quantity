# [roo_quantity 1.1.9](https://github.com/dejwk/roo_quantity/releases/tag/1.1.9)

Published 2026-08-29.

## roo_quantity 1.1.9

This release modernizes the host-testing and CI setup while making every bundled Arduino example runnable under the ESP32 emulator.

### Highlights

- Added runnable emulator targets for the Simple, Temperature, and Electronics examples.
- Migrated host emulation and CI to `roo_testing` 2.x Arduino ESP32 profiles.
- Added Bazelisk configuration and standardized AddressSanitizer support.
- Updated Roo dependencies: `roo_flags`, `roo_logging`, and `roo_time`.
- Fixed an extra format placeholder in the Electronics example and README snippet, eliminating example build warnings.

**Full Changelog:** https://github.com/dejwk/roo_quantity/compare/1.1.8...1.1.9
